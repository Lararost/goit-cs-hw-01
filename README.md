# goit-cs-hw-01

Домашнє завдання до модуля **«Архітектура комп'ютерів»**.

## Завдання 1

Файл: `task1.asm`

Програма модифікована на основі `calc.asm` з Chapter 01 та обчислює:

```text
b - c + a
```

Для:
```text
a = 5
b = 3
c = 2
```

результат:
```text
Result: 6
```

Компіляція на macOS:
```bash
nasm -f bin task1.asm -o task1.com
```

Потім `task1.com` запускається у DOSBox.

Перед здачею додайте до репозиторію скріншот DOSBox з результатом виконання.

## Завдання 2

Файл: `task2.py`

Інтерпретатор підтримує `+`, `-`, `*`, `/`, дужки та правильний пріоритет операцій.

Приклад:
```text
(2 + 3) * 4
```

Результат:
```text
20
```
