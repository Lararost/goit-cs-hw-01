Домашнє завдання до модуля «Архітектура комп'ютерів».

Завдання 1

Файл: task1.asm

Програма на асемблері обчислює:

b - c + a

У файлі задано:

a = 7
b = 10
c = 4

Очікуваний результат:

Result: 13

Для здачі потрібно скомпілювати та запустити програму у DOSBox і додати до репозиторію скріншот вікна DOSBox із результатом.

Приклад команд для TASM:

tasm task1.asm
tlink task1.obj
task1.exe

Команди можуть трохи відрізнятися залежно від того, як саме налаштований DOSBox і які асемблер/лінкер використовуються в курсі.

Завдання 2

Файл: task2.py

Інтерпретатор підтримує:

додавання +

віднімання -

множення *

ділення /

дужки ( )

правильний пріоритет арифметичних операцій

Приклад:

calc> (2 + 3) * 4
20

Запуск:

python task2.py

Додаткові приклади:

10 + 2 * 3        -> 16
(10 + 2) * 3      -> 36
20 / (2 + 3)      -> 4.0
7 - 3 + 2         -> 6
